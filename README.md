
# Publications

Лабораторная работа № 1 по дисциплине «Веб-программирование».

## Описание

Веб-приложение для создания, просмотра и хранения публикаций с фотографиями.

## Возможности

- Просмотр публикаций в виде плитки
- Просмотр отдельной публикации (лента)
- Фильтрация публикаций по площади
- Добавление публикаций с фотографиями
- Текстовые и числовые элементы
- Порядок наложения элементов (1–5)
- Хранение изображений в MinIO

## Технологии

- Python 3.11
- FastAPI
- Jinja2
- HTML и CSS
- MinIO (S3)
- Docker

## Запуск

1. Установить зависимости:

   pip install -r requirements.txt

2. Запустить MinIO на localhost:9000 и создать бакет publications.

3. Задать переменные окружения MINIO_ACCESS_KEY и MINIO_SECRET_KEY.

4. Запустить сервер:

   python -m uvicorn main:app --reload

5. Открыть http://127.0.0.1:8000/publications
